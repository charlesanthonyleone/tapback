# Pocket Nag: the working prototype

| Path | What it is |
|---|---|
| `lines.json` | 160 lines across 8 categories × visit tiers 1–4 plus big/small variants, keyword matching and display names (generated by `gen_lines.py`) |
| `picker.js` / `picker.py` | The line picker: cleans the merchant name, keeps a rolling 7-day per-merchant visit count and picks a line (`node -e` or `python3 picker.py "MCDONALD'S #4521" 8.49`) |
| `ios/IOS_BUILD_GUIDE.md` | Exact Shortcuts build: the Pocket Nag shortcut plus the Transaction/Wallet automation |
| `ios/lines_for_shortcuts.json` | A compact library to paste into the shortcut's Text action |
| `android/ANDROID_GUIDE.md` | The research on tap triggers, plus the MacroDroid and Tasker setup |
| `android/macrodroid_pocketnag.js` | Paste into MacroDroid's JavaScript Code action (rebuild with `build_macrodroid_script.py`) |
| `android/NATIVE_APP_SKETCH.md` | A NotificationListenerService app sketch |
| `SETUP_GUIDE.html` / `.pdf` | A plain-language guide for family, covering both phones and troubleshooting |

The website demo (`../index.html`) uses the same `picker.js` and `lines.json` (copied to `../pn-picker.js` and `../pn-lines.js`). If you edit lines, re-run `python3 gen_lines.py`, then `cp picker.js ../pn-picker.js && echo "window.PocketNagLines = $(cat lines.json);" > ../pn-lines.js`, then run `python3 ios/build_shortcuts_json.py` and `python3 android/build_macrodroid_script.py`.
